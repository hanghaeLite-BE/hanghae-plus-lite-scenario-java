# 항해 Lite 백엔드 코스 리뷰 세션 레포지토리 - Java

본 레포지토리는 항해 Lite 수강생들의 학습을 위하여 각 스탭에 대한 과제의 견본이 정리된 곳입니다.
- 항해 Lite의 수강생들이 제출한 과제물들을 바탕으로 구성된 세션 진행용 PR을 정리하여, 리뷰 세션 비디오 자료와 함께 보며 참고 할 수 있도록 하는 것이 본 레포지토리의 목적입니다.
- 본 레포지토리에 등록된 과제물은 **완벽한 정답이 아님을 꼭 알아주셨으면 합니다.**
